В дневнике нет записей с этими словами. Поиск ищет по началу слова и не разбирает русские словоформы, поэтому запись, где слово стоит в другой форме, может не найтись. Попробуйте слово покороче — например, только его начало.

    Сохранить архив

    Архив — это обычный zip-файл с текстовыми файлами внутри. Он открывается на любом компьютере без этого приложения, без пароля и без интернета. Создаётся он только тогда, когда вы нажимаете кнопку, и сохраняется туда, куда вы укажете.

    Фотографии, видео и звукозаписи в архив не входят.

    Резервной копии этих данных в облаке нет.

    Архив не зашифрован: ключ теряется быстрее, чем данные. Любой, кто получит этот файл, сможет его прочитать — храните его так же, как хранили бы бумажный семейный альбом.

    Приложение TheyGrow для Android

    Что это

    Список навыков по месяцам, ваши отметки о том, что ребёнок уже освоил, и занятия, которые с этими навыками связаны. Месяцы — это ориентир, по которому удобно искать, а не оценка и не диагноз: приложение ничего не измеряет и ни с кем вашего ребёнка не сравнивает.

    Где живут данные

    Имя, дата рождения, отметки и записи дневника хранятся в зашифрованном хранилище на самом телефоне. Они никуда не отправляются: у приложения нет ни аккаунта, ни синхронизации, ни копии в облаке — включая автоматический бэкап Android, который в нём выключен.

    Обратная сторона

    Копия одна. Если удалить приложение, записи исчезнут вместе с ним. Поэтому в приложении есть архив: оно собирает его на телефоне, по вашей команде, и никуда не передаёт.

    Как установить

    Файл .apk лежит на странице релизов; Android спросит разрешение на установку из неизвестных источников. Регистрация не нужна.

    Привет!

    Это приложение позволяет отслеживать прогресс твоего ребёнка и видеть список подходящих развивающих активностей. Все персональные данные хранятся только на этом устройстве и никуда не отправляются, что обеспечивает полную приватность. Позже функционал расширится, и потребуется регистрация, но сейчас всё работает без регистрации прямо на твоём устройстве.

    Чтобы весь функционал работал в полном объёме, нужно:

    1. создать профиль ребёнка (кнопка наверху) и указать его дату рождения;
    2. установить галочки напротив всех навыков, которые ребёнок к настоящему моменту уже освоил.

    Для каждого навыка в приложении сохранена подробная информация: суть навыка, диагностические признаки, возможные проблемы при освоении, доступные родителю активности для помощи в развитии и т.д. Чтобы увидеть информацию по навыку, нужно кликнуть по его названию в таблице.

    Чтобы развернуть группу навыков (крупная моторика, мелкая моторика и т.п.), нужно нажать на название группы.

    Кнопки, которые будут для тебя максимально полезными:

    1. "Показать навыки, готовые к освоению" - оставляет только навыки, которые ребёнок уже готов осваивать прямо сейчас: те, для которых всё необходимое уже освоено.
    2. "Подходящие активности" - выводит на экран наборы игр и других активностей, которые могут помочь упростить и ускорить освоение навыков, которые ребёнку ещё предстоит освоить.
